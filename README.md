# 鲜果优选后台管理系统

一个基于 Vue 3 + Element Plus 的水果业务后台管理系统,专注于水果批发零售业务场景。

## 🚀 技术栈

- **前端框架**: Vue 3.5.22 (Composition API)
- **UI组件库**: Element Plus 2.13.0
- **路由管理**: Vue Router 4.5.1
- **状态管理**: Pinia 2.1.7
- **构建工具**: Vite 7.1.7
- **HTTP客户端**: Axios 1.6.7
- **CSS预处理器**: Sass 1.71.1
- **图标库**: @element-plus/icons-vue

## ✨ 功能特性

### 📊 数据概览
- 实时数据统计展示
- 可自定义编辑的统计卡片(今日订单、营收、客户、库存)
- 热销水果排行榜
- 快捷操作入口
- 数据持久化保存(localStorage)

### 🛒 采购下单
- 水果采购表单
- 供应商信息管理
- 采购记录追踪
- 库存快速查询
- 采购历史管理

### 📦 库存管理
- 水果库存列表
- 库存数据可视化
- 库存预警提示
- 水果信息增删改查
- 新鲜度等级管理
- 统计数据自定义编辑

### 👥 用户管理
- 用户权限控制
- 登录认证系统

### ⚙️ 系统设置
- 基础配置管理
- 个性化设置
